# SIDE QUEST CLUB

The website behind the Side Quest Club shirts.

## Pages
- `index.html` — landing page with the waitlist.
- `p/index.html` — the page a shirt's QR code opens. Each shirt gets its own link: `p/?s=001`, `p/?s=002`, …

## Files you may want to edit
- `js/quests.js` — the quest decks (English and Spanish).
- `js/common.js` — settings. `WAITLIST_URL` must be filled in before sign-ups are saved.
- `css/style.css` — colours and look.

## Publishing (GitHub Pages)
Repo → Settings → Pages → Source: "Deploy from a branch" → `main` / root.
